# Code of Conduct

StackEmu is committed to a welcoming, respectful community. Participate constructively; be considerate of differing experience levels and identities; give feedback about work, not people; and respect privacy.

Harassment, discriminatory language, intimidation, deliberate disruption, sexualized content in community spaces, and publication of private information without permission are unacceptable.

Report concerns privately to the project maintainers through the contact published with the release repository. Maintainers will acknowledge reports, assess them fairly, protect confidentiality as practical, and choose proportionate action, including warning, content removal, temporary restriction, or removal from project spaces.

This policy applies in all project spaces and when representing the project publicly.
