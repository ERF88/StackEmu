## Scope / Escopo

Tailwind CSS/CLI 4.3.3 is wired into Maven/Docker without Preflight/default theme/CDN. The generated CSS retains the existing fingerprinted URL. Slate neutrals use developer-blue derivatives `#93c5fd` dark and `#1d4ed8` light. Shell utilities replace duplicated grid/flex/background declarations; desktop sidebar is 256px sticky/scrollable and returns to normal flow at <=900px. Header minimum is 80px. Native navigation/forms, routes, language/theme propagation, original filenames/MIME, CSP and CSRF are unchanged. No drawer, preview, deletion, presigning or new service was implemented.

Tailwind integrado ao Maven/Docker, sem reset/tema padrão/CDN, mantendo URL/hash. Paleta Slate/azul e migração delimitada do shell, com sidebar desktop sticky de 256px, mobile em fluxo normal e header mínimo de 80px. Contratos/fallback/segurança preservados; nenhuma nova capacidade S3.
