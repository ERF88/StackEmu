# Expanded S3 operational scope / Escopo operacional S3 ampliado

Date / Data: 2026-10-15. User-confirmed requirement, not implemented-capability evidence / Requisito confirmado pelo usuário, não evidência de capacidade implementada.

Decision record / Registro da decisão: [ADR-0014](../decisions/ADR-0014-expanded-operational-s3-scope.md). Slice evidence / Evidência das fatias: [UX-2A](../spikes/ux-2a-results.md), [UX-2B](../spikes/ux-2b-results.md), [UX-3](../spikes/ux-3-results.md).

## First delivery boundary / Limite da primeira entrega

The user expanded the current first functional delivery to full **operational** S3 management: buckets, logical folders/prefixes, objects, preview, upload/download, copy/move, deletion, clipboard and presigned URLs. This is the current UX/S3 delivery, not a rewrite of the historical Phase 1 skeleton or its test evidence. Implement incrementally on Quarkus/Qute/htmx; do not claim the whole scope is implemented when one slice passes.

O usuário ampliou a primeira entrega funcional atual para gerenciamento **operacional** S3: buckets, pastas lógicas/prefixos, objetos, preview, upload/download, cópia/movimentação, exclusão, clipboard e URLs assinadas. É a entrega UX/S3 atual, não reescrita da Fase 1 histórica. Implementar incrementalmente na stack existente; uma fatia aprovada não conclui todo o escopo.

Advanced bucket settings are explicitly outside this delivery: version-management UI, policies/ACL editors, CORS/lifecycle/encryption/notification configuration and similar administration. Detecting versioning state for safe deletion is still necessary; excluding a version-management UI is not permission to ignore versions. Other AWS services and full AWS-console parity remain out of scope.

Configurações avançadas ficam fora: UI de versões, editores de políticas/ACLs, CORS/lifecycle/criptografia/notificações e administração semelhante. Detectar versionamento para excluir com segurança continua necessário; excluir UI de versões do escopo não permite ignorar versões. Outros serviços e paridade com todo o console AWS continuam fora.

## Non-negotiable gates and unknowns / Gates e incógnitas

User scope approval does not remove technical gates. Reads/mutations remain separate; metadata/listing must not imply extra per-object HEAD calls. Native routes/forms, same-origin local assets, escaped opaque keys, CSP, CSRF and original-file rules remain. No production resources or automatic retries of destructive operations. Unknown/unsupported version state fails closed; never silently delete current versions, markers or unrelated keys. Bulk work needs explicit paginated limits, timeouts, cancellation semantics and per-target outcomes before implementation; UI confirmation alone is insufficient.

Aprovação do escopo não elimina gates técnicos. Separar leituras/mutações, sem HEAD adicional por objeto para decorar listagem. Preservar fallback, assets locais, chaves escapadas, CSP/CSRF e arquivo original. Sem produção/retry destrutivo automático. Estado de versão desconhecido/não suportado deve bloquear exclusão; não remover versões/markers/chaves sem contrato explícito. Lotes exigem limites paginados, timeouts, cancelamento e resultados por alvo; modal não basta.

Preview must reject active HTML/SVG/scripts/remote embeds, validate allowed raster data beyond filename/MIME, and bound bytes/time/dimensions/decompression. Unsupported content retains attachment download. Signed URLs are bearer-like secrets: define TTL caps, reachable authority/host, safe signing credentials, response attachment headers, cache/log/screenshot treatment and emulator expiry/tampering tests. Clipboard denial or absent secure-context APIs must retain selectable text, never false success. Exact numeric limits and compatibility results remain unverified until their spikes; do not invent them.

Preview deve recusar HTML/SVG/scripts/embeds ativos, validar raster além de nome/MIME e limitar bytes/tempo/dimensões/descompressão, mantendo download de anexo para não suportados. URLs assinadas são segredos de portador: definir TTL, host acessível, credenciais, anexo, cache/log/capturas e testes de expiração/adulteração. Clipboard negado/API ausente exige texto selecionável, sem falso sucesso. Limites numéricos e compatibilidade permanecem não verificados até os spikes.

Acceptance requires fresh Java 25/local MiniStack, style, native/no-JS, keyboard/theme/language, hostile-key/content, permission/error/race, exact mutation-target and signed-link tests as applicable. Existing phase counts do not prove new capabilities. Human acceptance, legal/name validation and public release remain separate; StackEmu is not AWS affiliated.

Aceite exige nova evidência Java 25/MiniStack local, estilo, fallback/teclado/temas/idiomas, entradas hostis, erros/concorrência, alvos exatos e links assinados conforme aplicável. Contagens antigas não comprovam capacidades novas. Aceite humano, validação do nome/jurídico e release permanecem separados, sem afiliação com AWS.
