# Component accessibility contracts / Contratos de acessibilidade

The `/components` gallery contains illustrative values, not emulator status. Real hover/focus are exercised by keyboard/pointer tests, not fake focus classes. No sample button performs a mutation. / A galeria usa valores ilustrativos, não o estado do emulador. Hover/foco são exercitados de verdade; botões de exemplo não alteram dados.

## Verification and limits / Verificação e limites

UX-5A text content uses a labelled, focusable preformatted region with bounded vertical scrolling, wrapping long lines and visible focus. Object key/body remain escaped text; explicit native preview/back/attachment links work without JavaScript. Unsupported content gives an explanation plus attachment fallback, not a blank or truncated success surface. Real-object tests exercise this component; gallery examples do not fetch arbitrary object content. [ADR-0018](../decisions/ADR-0018-bounded-text-preview.md). / Texto usa região preformatada rotulada/focável com rolagem limitada, quebra de linhas longas e foco visível. Chave/corpo escapados e links nativos sem JS; recusa explica e mantém anexo, sem sucesso vazio/truncado. Testar objetos reais, sem galeria buscar conteúdo arbitrário.

UX-5B image preview uses a native image with translated alt/description, bounded responsive geometry, persistent original-download/back links and native no-JS fallback. Local JS updates only a polite status on loading/confirmed image load/error and hides the broken image; no autofocus, focus trap, automatic retry or active object markup. The generic native fallback never claims the shell's 200 means a successful preview. Content errors retain exact localized reasons for direct requests; the image element itself does not render those text bodies. Test both languages/themes at mobile/desktop, native and enhanced failure, keyboard links and axe; human screen-reader acceptance remains separate. / Imagem nativa com alt/descrição traduzidos, dimensões responsivas limitadas, links persistentes e fallback sem JS. Script só atualiza status discreto e oculta imagem quebrada, sem foco/retry/markup ativo. Fallback não confunde shell 200 com sucesso; motivo HTTP exato não é mostrado pelo elemento img. Testar idiomas/temas/mobile/desktop/falhas/teclado/axe; aceite humano separado.

UX-4 result notices follow [ADR-0017](../decisions/ADR-0017-operation-notifications.md): one labelled region, polite status only on native success navigation, no duplicate live announcement after focused upload replacement, no timer/autofocus/overlay, native dismiss button and focus return to the persistent result heading. The gallery does not fabricate operation success; real local-operation tests exercise this component. Existing clipboard feedback stays modal-local. Destructive dialogs remain a documented contract, not a gallery/demo capability. / Avisos têm região rotulada, polite só na navegação nativa, sem duplicar anúncio de upload, timer/autofoco/overlay; fechar por teclado retorna ao título persistente. Galeria não simula sucesso; testes reais validam componente. Clipboard permanece local; diálogo destrutivo não foi ativado.

Browser tests cover gallery/real pages in English/Portuguese and dark/light, keyboard refresh, scroll regions, native validation, unavailable/error fixtures and visual snapshots. Token checks cover opaque color pairs. These are partial evidence, not full WCAG certification or proof across browsers, assistive technologies, forced-color palettes or operating systems. Manual screen-reader and wider browser review remain required. / Testes cobrem idiomas, temas, teclado, erros e snapshots; tokens cobrem pares opacos. Evidência parcial, não certificação WCAG ou de todos os navegadores/leitores/paletas/sistemas. Revisão manual continua necessária.
