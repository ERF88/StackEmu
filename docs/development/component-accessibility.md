# Component accessibility contracts / Contratos de acessibilidade

The `/components` gallery contains illustrative values, not emulator status. Real hover/focus are exercised by keyboard/pointer tests, not fake focus classes. No sample button performs a mutation. / A galeria usa valores ilustrativos, não o estado do emulador. Hover/foco são exercitados de verdade; botões de exemplo não alteram dados.

| Component / Componente                   | Semantics and states / Semântica e estados                                                                                                 | Keyboard / Teclado                                                                          |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------- |
| Shell / Shell                            | landmarks, skip link, current navigation, labelled preferences / landmarks, skip e preferências rotuladas                                  | Tab, Enter; skip moves focus to main / skip foca main                                       |
| Button/link / Botão/link                 | native elements, visible text, disabled attribute, focus/hover supplementary / elementos nativos e estados explícitos                      | Enter/Space for buttons; Enter for links; disabled skipped / botão Enter/Espaço, link Enter |
| Status/error / Estado/erro               | text + icon, status polite, alert only for errors / texto + ícone, status educado e alerta de erro                                         | no focus stealing / não roubar foco                                                         |
| Refresh / Atualização                    | busy content, status outside busy region, retained trigger, stale-result failure text / conteúdo ocupado, status externo e foco preservado | Enter; duplicate in-flight requests dropped / duplicatas descartadas                        |
| Form fields / Campos                     | associated label/help/error, aria-invalid, readonly selectable, file reselection explained / rótulos, erros e ajuda associados             | Tab; native file picker; no custom keyboard capture / seletor nativo                        |
| Confirmation / Confirmação               | native required checkbox with meaningful label / checkbox obrigatório rotulado                                                             | Space toggles / Espaço alterna                                                              |
| Submit / Envio                           | native POST; busy state disables only submit button, preserves payload; pageshow reset / POST e payload preservados                        | Enter; no server-idempotency claim / sem garantia de idempotência                           |
| Tables / Tabelas                         | caption, row/column headers, labelled focusable overflow region, opaque sticky headers / caption, cabeçalhos e região rolável              | Tab into region/links, arrow scrolling / Tab e setas                                        |
| Breadcrumb/pagination / Trilha/paginação | named nav, current page, native links, opaque cursors / nav rotulada e cursores opacos                                                     | Tab/Enter; no invented previous cursor / sem cursor anterior inventado                      |
| Disclosure / Painel expansível           | native details/summary, no duplicate heading / elemento nativo sem título duplicado                                                        | Enter/Space; no focus trap / sem prender foco                                               |
| Preview/download / Prévia/download       | labelled readonly mono textarea; attachment link, original name/type policy / textarea rotulada, anexo e política original                 | selection/copy and native link / seleção/cópia e link                                       |
| Empty / Vazio                            | descriptive text and implemented next link / texto e próximo link real                                                                     | Tab/Enter; navigation is not mutation / navegar não é alterar                               |

## Verification and limits / Verificação e limites

Browser tests cover gallery/real pages in English/Portuguese and dark/light, keyboard refresh, scroll regions, native validation, unavailable/error fixtures and visual snapshots. Token checks cover opaque color pairs. These are partial evidence, not full WCAG certification or proof across browsers, assistive technologies, forced-color palettes or operating systems. Manual screen-reader and wider browser review remain required. / Testes cobrem idiomas, temas, teclado, erros e snapshots; tokens cobrem pares opacos. Evidência parcial, não certificação WCAG ou de todos os navegadores/leitores/paletas/sistemas. Revisão manual continua necessária.
