# ADR-0024 — Direct controls and predictable navigation / Controles diretos e navegação previsível

- Date / Data: 2026-10-20.
- Status / Estado: Implemented direction; local verification and maintainer acceptance tracked separately / Direção implementada; verificações e aceite separados.

## Decision / Decisão

Maintainer feedback rejects the in-flow Actions/Preferences expansions and inconsistent controls. Under ADR-0022/0023 and apple-hig-designer, explicitly supersede ADR-0020's quiet-shell disclosure interaction, not its service-centered information architecture. Previous results remain historical.

Feedback do mantenedor rejeita expansões de Ações/Preferências e controles inconsistentes. Com ADR-0022/0023 e a skill, substituir explicitamente a interação em disclosure da ADR-0020, sem mudar a arquitetura centrada em serviços. Resultados anteriores continuam históricos.

- Preferences uses a labelled native `popover="auto"`, opened by a real button. It overlays rather than resizing the header/main. The browser supplies Escape, outside-click dismissal and keyboard order; an explicit labelled close control is available. It is nonmodal, not an ARIA menu or dialog. Language/theme labels remain visible and ordinary URL links. No new controller, storage or polling. / Preferências em popover nativo não modal, sem deslocar conteúdo; Escape/clique externo/ordem nativos e fechamento explícito, com links e rótulos visíveis.
- Without JS, supporting browsers retain the same declarative interaction. Browsers without the popover selector receive visible in-flow preferences and no inert toggle/close buttons; this compatibility fallback is intentionally not the primary presentation. No claim of testing every older browser. / Sem JS, interação declarativa preservada; navegadores sem suporte recebem preferências visíveis no fluxo, sem botões inertes. Fallback não é a apresentação principal nem prova de compatibilidade universal.
- Bucket names open the explorer; row actions directly expose Upload and Create folder. Object rows expose Download, Details and conditional Delete-review. Text/image preview and clipboard live in the existing detail surfaces; preview gates remain intact. Do not duplicate browse in an expanding menu or fabricate copy/move/signing actions. / Nome do bucket abre explorer; ações diretas de envio/pasta. Objetos oferecem download, detalhes e revisão de exclusão condicional; prévias/cópia nos detalhes reais, sem capacidades fictícias.
- Standalone actions share `.button`, icon plus meaningful label, primary/secondary/danger variants and minimum 48 CSS px. Icon-only close in Preferences has an accessible name. Icons are local decorative SVGs, not downloaded Apple assets. Submitting updates the label span, preserving its icon. Navigation remains native links, not buttons or click-only elements. / Ações com componente comum, ícone/rótulo e variantes, mínimo 48px; fechamento compacto rotulado. SVGs locais decorativos; envio preserva ícone ao atualizar texto. Navegação continua link nativo.
- Explorer breadcrumbs precede the heading; details, preview, forms, deletion review and diagnostics put a contextual return before the title. Remove duplicate bottom return links; upload retains its separate explicit reload action. No SPA/history interception or route/target rewriting. Density stays listing-local, visually aligned with the list heading. / Breadcrumb antes do título; retorno contextual antes do título nas demais telas. Sem duplicatas inferiores, SPA ou reescrita de rotas/alvos; recarga explícita do upload preservada e densidade alinhada à listagem.
- Table headers wrap at word boundaries; object size/date columns reserve at least 7rem/11rem so direct actions cannot crush their labels. Preserve full key wrapping and table-local scrolling rather than hiding values or causing page overflow. / Cabeçalhos sem quebra no meio de palavras; tamanho/data com mínimo 7rem/11rem, mantendo chaves completas e rolagem apenas da tabela.

## Boundaries and validation / Limites e validação

Preserve Home's zero emulator I/O, implemented-services-only navigation, exact encoded keys and `lang/theme/density`, native forms/links, checked Qute, original files, CSP/CSRF, bounded previews and one-use ETag/version-gated deletion. No new S3 capability, runtime dependency, app image, publication or release. Functional bucket metadata/help disclosures remain informational, not action menus.

Preservar Home sem I/O, navegação só com serviços implementados, alvos exatos/preferências, fallback/Qute/arquivo original/CSP/CSRF/prévias limitadas e exclusão confirmada com versão/ETag. Sem capacidade, dependência, imagem ou publicação nova. Disclosures informativos de metadados/ajuda não são menus de ações.

Verify actual opening/closing, keyboard/focus return, unchanged heading position, direct native actions, contextual returns, no-JS, both languages/themes/densities and 390/1440px without page overflow. Retain table-local scrolling and complete opaque keys. Run local Java 25/Maven and established checks; only MiniStack runs in Docker. [Execution record](../evidence/direct-controls-results.md). Maintainer visual/assistive-technology acceptance, final new-image/Linux comparison and StackEmu legal/name validation remain pending; no HIG/WCAG certification or user-research result is implied.

Verificar interação/foco/posição estável/ações/retornos/fallback/preferências/layouts, mantendo rolagem local da tabela e chaves completas. Checks Java e ferramentas locais; Docker só MiniStack. Aceite humano, imagem final/Linux e nome/jurídico continuam pendentes, sem certificação ou pesquisa inventada.
