# ADR-0021 — Single-object deletion / Exclusão individual

- Date / Data: 2026-10-20.
- Status / Estado: ACCEPTED implementation contract for the maintainer-authorized deletion slice; verification and human acceptance separate / Contrato de implementação ACEITO para a fatia de exclusão autorizada; verificação e aceite humano separados.

## Contract / Contrato

2026-10-22: [ADR-0027](ADR-0027-empty-folder-removal.md) supersedes the marker exclusion below only for verified zero-byte empty-folder entries. No recursive deletion is authorized. / Substitui a exclusão de markers abaixo apenas para entrada de pasta comprovadamente vazia; sem exclusão recursiva.

2026-10-21: [ADR-0025](ADR-0025-action-dialogs.md) supersedes native-page-only/no-modal presentation and the generic checkbox. Explicit Delete in a reviewed action window expresses consent; one-use tickets, CSRF, exact server-held targets, version/ETag gates and uncertainty remain unchanged. / Modal e envio explícito substituem apresentação anterior, sem dispensar os gates de exclusão.

Implement only one exact non-marker key in a never-versioned bucket. No traversal, batch, prefix cleanup, bucket deletion, explicit version IDs or retention bypass. GET `/s3/delete-object?bucket=…&key=…` reads version state and HEAD metadata; it cannot delete. POST to the same path requires framework CSRF, explicit confirmation and a random 256-bit opaque ticket. The bounded process-local store holds the reviewed target/ETag for five minutes, at most 128 pending tickets. The POST atomically consumes a ticket before any service I/O, including failures. Restart invalidates tickets. No browser storage, signing secret, application session or new dependency is introduced. Tokens are not authentication; localhost/trusted-emulator restrictions remain.

Implementar apenas uma chave exata que não termine em `/`, em bucket nunca versionado. Sem percorrer prefixos, lotes, limpeza/exclusão de buckets, IDs de versão ou bypass de retenção. GET consulta estado e HEAD, sem excluir. POST exige CSRF, confirmação e ticket opaco aleatório de 256 bits. Servidor guarda alvo/ETag por cinco minutos, máximo de 128 confirmações; consumo atômico antes de I/O, inclusive falhas. Reinício invalida tickets. Sem armazenamento no navegador, segredo de assinatura, sessão ou dependência nova. Ticket não autentica; restrição local permanece.

Only a successful compliant GetBucketVersioning response with omitted Status and MFADelete is accepted as never-versioned. Enabled, Suspended, unknown values and read errors fail closed. A non-null object version other than the literal `null` is refused. Recheck bucket state immediately before DELETE and send the exact reviewed ETag as If-Match, never `*`. The installed SDK 2.54.13 has no per-request retry override: use an adapter-owned client derived from the managed client's public endpoint/region/credentials, forced path style and a dedicated URLConnection transport (1s connect/socket, 3s API/2s attempt). Use a fresh override configuration with AwsRetryStrategy.doNotRetry() for that client, including its reads. Copying the resolved managed overrides was rejected by local tests because the inherited retry strategy replaced the new setting; close only the owned client at destruction, never the shared client or explicitly its credentials provider. This is a scoped lifecycle exception to ADR-0004/naming guidance, like the preview exception, not a general client factory. Advanced custom client/proxy/auth settings remain unverified. The DELETE also carries Content-Length: 0 and an explicit empty RequestBody supplied by a narrowly scoped SDK interceptor; this enables fixed-length URLConnection output without global JVM properties. A lost-response fixture must observe one wire DELETE, not merely one SDK attempt. Header-only fixed-length mode without a body was rejected because it prevented transmission. Disable SDK retries for this destructive request; never automatically retry from the UI. A changed ETag is conflict, not success. Tokens cannot change their server-held bucket/key/ETag via hidden-field tampering or replay. Existing conservative write-target validation applies; markers and unsupported names remain read-only.

Somente resposta bem-sucedida e conforme ao protocolo sem Status/MFADelete é aceita como nunca versionado. Enabled, Suspended, valores desconhecidos e erros são recusados, assim como versão do objeto diferente de ausente/`null`. Revalidar antes do DELETE e usar If-Match exato, sem wildcard. SDK 2.54.13 não possui override de retry por requisição: cliente próprio derivado da configuração pública do gerenciado (endpoint/região/credenciais), path style e transporte URLConnection dedicado (conexão/socket 1s, API 3s/tentativa 2s), configuração de overrides nova com AwsRetryStrategy.doNotRetry(), inclusive leituras. Copiar overrides resolvidos foi rejeitado nos testes: a estratégia herdada substituía a configuração nova. Encerrar só cliente próprio, nunca o compartilhado nem explicitamente seu provider. Exceção delimitada de lifecycle à ADR-0004/guia de nomes, semelhante ao preview, não fábrica genérica. Configuração avançada/proxy/auth customizada não verificada. DELETE também usa Content-Length: 0 e RequestBody vazio via interceptor SDK delimitado, ativando saída de comprimento fixo sem propriedade global da JVM. Fixture de resposta perdida deve observar um DELETE na rede, não só tentativa SDK. Somente o cabeçalho sem corpo foi rejeitado por impedir envio. Sem retry SDK/navegador. ETag alterado resulta em conflito. Campos enviados não alteram alvo guardado; ticket consumido não pode ser reutilizado. Validação conservadora de escrita permanece; markers/nomes não suportados seguem somente leitura.

## Threats and residual limits / Ameaças e limites

The ticket is an unguessable, short-lived capability, not identity/access control. CSRF is independently mandatory. Never log tickets, SDK failures, credentials or emulator response bodies. Escaped Qute renders opaque keys; query values are encoded, not path segments. Native confirmation pages work without JavaScript and preserve language/theme/density. Cancel is a read-only link. There is deliberately no mutation htmx/modal shortcut or optimistic success.

Ticket é capacidade temporária imprevisível, não identidade/controle de acesso. CSRF independente obrigatório; não registrar tickets, falhas SDK, credenciais ou corpo do emulador. Qute escapa chaves e links codificam query. Confirmação nativa mantém idioma/tema/densidade e funciona sem JavaScript; cancelar é link de leitura. Sem atalho htmx/modal ou sucesso otimista.

S3 cannot atomically condition DELETE on bucket version state. External writers must not toggle versioning during this local workflow. A concurrent version change may create a delete marker despite the prior check; version/delete-marker response headers produce an uncertain result, never a claim of rollback or permanent removal. ETag is not an object-generation identifier: identical bytes or metadata-only replacement may retain it. HTTP success acknowledges the conditional request, not permanent absence against concurrent writers. Transport/5xx failure after submission is uncertain and consumes the ticket; inspect the resource before any new manual attempt. A protocol-incompatible emulator silently omitting version state cannot be distinguished from a compliant never-versioned bucket. Only the tested local MiniStack baseline is supported, not arbitrary endpoints or production AWS.

S3 não condiciona DELETE atomicamente ao estado do bucket. Não alterar versionamento externamente durante o fluxo. Mudança concorrente pode criar marker; cabeçalhos de versão/marker produzem resultado incerto, sem alegar rollback/exclusão permanente. ETag não identifica geração: bytes idênticos ou só metadados podem preservá-lo. Sucesso confirma solicitação condicional, não ausência definitiva com escritores concorrentes. Falha de transporte/5xx após envio é incerta e consome ticket; inspecionar antes de nova tentativa manual. Emulador não conforme que omite estado não é distinguível de resposta válida. Suporte restrito ao MiniStack local testado, não endpoint arbitrário/AWS produção.

## Gates / Gates

Before exposing action links: exact-key conditional deletion through installed signed SDK; mismatch/replacement refusal with neighboring resource preserved; version-state refusal before and after confirmation; missing/invalid/replayed ticket, missing confirmation and CSRF refusal; bounded expiry/capacity; explicit ambiguous-outcome handling. Run host Java 25/Maven and local browser/style checks. Docker remains emulator-only; new-image/consolidated container validation is separate. Legal/name validation and human accessibility/release acceptance remain pending. No research results are implied.

Antes de expor links: SDK instalado/assinado, alvo exato, recusa de ETag alterado, vizinho preservado, versionamento antes/depois da confirmação, ticket/consentimento/CSRF inválidos, expiração/capacidade e tratamento de incerteza. Verificar Java 25/Maven e navegador/estilo locais. Docker só emulador; imagem nova separada. Nome/jurídico, acessibilidade humana e release pendentes, sem pesquisa inventada.
