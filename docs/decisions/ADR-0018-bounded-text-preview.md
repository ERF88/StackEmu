# ADR-0018 — bounded text preview / Preview de texto limitado

- Date / Data: 2026-10-15.
- Status: Accepted UX-5A implementation contract; fresh evidence required / Contrato UX-5A aceito; exige evidência nova.

## Boundary and threats / Limite e ameaças

This first UX-5 slice previews complete small text/JSON as escaped text on a separate native GET page. It does not complete raster preview or the expanded S3 delivery. Treat object keys, metadata and body as hostile: prevent active markup, remote embeds, unbounded reads, decompression, invalid encoding, misleading partial results and error-detail leakage. Only the configured S3 client is used; bucket/key are opaque encoded query values, never a filesystem path or arbitrary URL. No automatic content fetch during listing/detail/drawer, and no mutation or presigning. Preview is local-development tooling, not authentication or a malware scanner.

Primeira fatia UX-5 mostra texto/JSON pequeno completo como texto escapado em página GET separada. Não conclui imagens nem entrega S3 ampliada. Chaves/metadados/corpo são hostis: impedir markup ativo, embeds, leitura ilimitada, descompressão, encoding inválido, resultado parcial enganoso e detalhes internos. Usar só cliente S3 configurado; bucket/chave são query codificada, nunca caminho/URL arbitrária. Sem buscar conteúdo automaticamente na lista/detalhes/drawer, mutação ou assinatura. Não autentica nem faz antivírus.

## Chosen policy, not measured capacity / Política escolhida, não capacidade medida

- Maximum complete input: 65536 bytes (64 KiB), including UTF-8 BOM. Read at most 65537 bytes to detect excess, irrespective of Content-Length. Reject excess instead of truncating; reject advertised oversized content before reading. Empty text is supported. These are conservative product limits, not research/throughput results.
- Require `.txt`/`.log` plus `text/plain`, or `.json` plus `application/json`, case-insensitive. Optional UTF-8 charset only; reject unknown/generic/conflicting MIME, other parameters and nonidentity Content-Encoding. Never decompress. No byte format is inferred solely from metadata: validate the bounded actual bytes too.
- Strict UTF-8 decoding without replacement; remove one leading BOM. Reject C0 controls except tab/CR/LF, DEL/C1 and bidi override/isolate controls. Render only escaped text, never Markdown, HTML, JSON tree, iframe, object, embed, image, script or automatic link. JSON is shown verbatim; syntax validity/pretty printing is not promised.
- One managed synchronous SDK transformer consumes bounded chunks before returning and aborts every exit, avoiding drain. A first stalled-body test disproved that API timeout alone interrupts URLConnection reads. A named-builder attempt failed CDI resolution on the installed extension. Instead create one adapter-owned preview client from the managed client's public endpoint/region/credentials-provider/override configuration, using this project's path-style baseline and a separate URL transport (1-second connect, 2-second socket timeout). Close only the owned client on destruction, never mutate/close the managed download client or explicitly close its credentials provider. No duplicate credential properties or browser-provided endpoint. API/attempt budgets stay 3/2 seconds, plus an explicit 3-second monotonic body deadline checked between chunks; a blocked read may add a socket interval to detection, not a hard real-time guarantee. This scoped lifecycle exception is for the local static-credentials/path-style baseline; advanced/custom provider/proxy/TLS/endpoint-provider settings need separate verification. Test stalled and trickling body behavior; do not reuse the unmanaged attachment stream.

Máximo completo de 65536 bytes, lendo até 65537 para detectar excesso, sem truncar. Exigir extensão/MIME/charset/UTF-8/controles válidos, sem compressão/interpretação. JSON verbatim não significa sintaxe validada. Teste provou insuficiência do timeout API para URLConnection bloqueado; builder nomeado também falhou resolução CDI. Cliente próprio passa a reutilizar endpoint/região/provider/overrides públicos do cliente gerenciado, com path-style local, conexão 1s/socket 2s, API/tentativa 3s/2s e prazo monotônico de corpo 3s entre blocos. Fechar só cliente próprio, sem alterar/fechar cliente gerenciado/provider, duplicar credenciais ou aceitar endpoint do navegador. Detectar prazo pode somar intervalo de socket. Configurações avançadas exigem verificação separada; testar bloqueio/gotejamento sem prometer tempo real.

## HTTP and UX / HTTP e UX

New contract: `/s3/preview?bucket=…&key=…`, with normal language/theme query propagation and an explicit link from full object details. Full-page navigation is also the no-JS path. Do not add a link to historical gallery fixtures or fetch object bytes from the drawer in this slice. Always retain original attachment download and back-to-details links. Escaped preformatted, labelled, bounded-scroll text; unsupported/oversized/invalid content has an explicit localized explanation and no body. Policy refusal uses 200 (the explanatory page), not a false successful content preview. Missing/denied/invalid/unavailable/SDK failures retain 404/403/400/503/502; no raw emulator diagnostics. Success and error responses use no-store plus existing nosniff, no-referrer, frame denial and unchanged self-only CSP. No new binary-inline endpoint or relaxed CSP.

Nova rota GET query codificada com idioma/tema e link explícito nos detalhes completos. Página nativa funciona sem JS; galeria histórica e drawer não passam a buscar conteúdo. Manter download original/anexo e retorno aos detalhes. Texto preformatado rotulado com rolagem limitada; recusa localizada sem corpo, status 200 da explicação, não falso preview. Erros mantêm status reais e mensagens sanitizadas. Todas as respostas sem cache e com política CSP/cabeçalhos existente; sem endpoint binário inline ou CSP relaxada.

## Remaining gates / Gates restantes

Raster preview is still required in this first delivery but not enabled by this ADR. It needs format/signature validation, compressed-byte/pixel/dimension/decode/output limits, metadata stripping/re-encoding, runtime codec/native-library validation and hostile-image tests before activation. HTML/SVG/PDF/archives/active documents stay unsupported. No deletion, copy/move or signed URL work is implied. Legal/name validation and human assistive-technology acceptance remain pending. Fresh results: [UX-5A evidence](../spikes/ux-5a-results.md).

Imagens continuam exigidas na primeira entrega, não ativadas aqui: validar assinatura/formato, bytes/pixels/dimensões/decode/saída, remover metadados/reencodar, conferir codecs/bibliotecas e conteúdo hostil. HTML/SVG/PDF/arquivos compactados/documentos ativos não suportados. Demais capacidades, nome/jurídico e aceite humano pendentes.

References consulted / Referências: [SDK transformer lifecycle](https://docs.aws.amazon.com/java/api/latest/software/amazon/awssdk/core/sync/ResponseTransformer.html), [SDK timeout layers](https://docs.aws.amazon.com/sdk-for-java/latest/developer-guide/timeouts.html). The unmanaged input-stream exception is why preview must consume within a managed transformer; verify the pinned SDK implementation rather than assuming latest documentation is test evidence.
