## Errors and limits / Erros e limites

Initial object page size is 50 with a continuation token. Do not load whole collections or count every object while rendering a bucket list. Handle `NoSuchBucket`, optional absent tags, unavailable endpoint, and unsupported operation predictably. User messages must contain no secrets, stack traces, or internal responses; technical logs need diagnostic context without credentials/content.

## Remaining operational work / Operações restantes

Single-object deletion and bounded previews now have their own implemented contracts; see the links above and current status for evidence. Bucket empty/delete, bulk/prefix deletion, copy/move and presigning remain first-delivery work, not optional MVP+ candidates. They require separate pagination/batching/version/partial-failure or signing policies before exposure. Move is verified copy plus delete, not atomic rename. Metadata editing and explicit-version deletion remain excluded.

Exclusão individual e previews limitados possuem contratos próprios implementados, com evidências no status atual. Esvaziar/excluir bucket, exclusão em lote/prefixo, cópia/movimentação e assinatura continuam na primeira entrega, com gates próprios de limites/versão/falhas/assinatura antes de exposição. Movimentar é copiar e excluir após verificação, não rename atômico; edição de metadados e versões explícitas não incluídas.

## Acceptance evidence / Evidência de aceite

Before calling a behavior supported, run integration tests against a pinned emulator for nested prefixes, pagination, boundary/over-limit upload, large streaming download with controlled memory, special/Unicode object keys, failure during streaming, and versioned buckets where applicable.
