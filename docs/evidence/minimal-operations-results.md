# Minimal workspace and durable operations — local results / Resultados locais

Date / Data: 2026-10-23. Direction / Direção: [ADR-0029](../decisions/ADR-0029-minimal-workspace-operations.md). Contracts / Contratos: [S3 operations](../development/s3-operations.md). Local working tree, not a published release or maintainer acceptance. / Árvore local, não release publicada nem aceite do mantenedor.

## Delivered / Entregue

Minimal action dialogs have one title/target/consequence, no technical expanders or per-item reports, and automatic return after confirmed success or accepted asynchronous work. Feedback distinguishes completion from initiation, partial results and uncertainty. Object metadata and operation results have separate canonical pages; Home remains a service catalog with zero emulator calls. / Diálogos mínimos, sem expansores/relatórios, com retorno automático e feedback que distingue início/conclusão/falha parcial/incerteza. Metadados/resultados em páginas próprias; Início sem chamadas ao emulador.

The implementation adds file H2 persistence, immutable paginated inventories, explicit start/interruption/reconciliation, endpoint binding and immediate intent commits; version/delete-marker/prefix cleanup, individual copy/move, conditional replacement and presigned downloads. Only bucket deletion requires its name. Native routes and URL preferences remain. / Implementação adiciona persistência H2, inventário paginado imutável, início/interrupção/reconciliação explícitos, vínculo ao endpoint e commits imediatos; limpeza de versões/markers/prefixos, cópia/movimentação, substituição condicional e download assinado. Apenas bucket exige nome; rotas/preferências preservadas.

## Delivery boundaries / Limites da entrega

JavaScript/CSS/docs checks and 44 contrast comparisons passed locally, together with PowerShell analysis, local smoke, Compose configuration and whitespace. Final style log: `work/minimal-delivery-checks.log`. Only MiniStack runs in Docker. The GUI runs on the host JVM with loopback binding; its exact process ID is operational, not a stable product contract. / Checks locais/44 comparações de contraste aprovados; somente MiniStack em Docker e GUI JVM em loopback.

All mutations during tests targeted generated owned fixtures. The 73 browser-generated operation records were inspected: zero non-test targets and zero active jobs. A byte-identical database backup was saved under `work/minimal-browser-history-backup/operations.mv.db` before removing only those test records from the visible journal. Existing user buckets were not removed. / Alterações somente em fixtures próprias; 73 registros de testes preservados em backup antes da limpeza do histórico, sem remover buckets do usuário.

The new image recipe includes the H2 notice and a writable persistent volume; no new application image/container suite was executed. No fresh vulnerability scan, Git commit/push/tag or release was performed. Emulator signature-expiration enforcement, other emulators/platforms, adversarial external writers, human usability/accessibility acceptance and StackEmu legal/name validation are not certified by these results. / Receita de imagem preparada, validação final separada; sem scan/publicação novos nem certificação de compatibilidade, pesquisa, acessibilidade ou nome/jurídico.
