# Direct controls — local results / Controles diretos — resultados locais

Dates / Datas: implementation began 2026-10-20; verification resumed 2026-10-21 / implementação iniciada em 20/10, verificação retomada em 21/10. Scope / Escopo: [ADR-0024](../decisions/ADR-0024-direct-actions-navigation.md).

## Audit and change / Auditoria e mudança

Source inspection and the host Chrome capture `work/controls-before.png` confirmed Preferences expands the entire header and shifts S3 down, while row Actions require a second expansion. Shared controls, detail/copy/close actions and return links used mixed presentations and positions. These are implementation observations, not user-research findings.

Fontes e captura local confirmaram crescimento do cabeçalho, deslocamento do S3 e expansão adicional nas linhas, com apresentações/retornos inconsistentes. São observações da implementação, não pesquisa com usuários.

Replaced action disclosures with direct existing links, Preferences with a native nonmodal popover, and inconsistent standalone controls with shared icon/label buttons. Standardized contextual returns before titles and breadcrumbs before explorer headings. Submit feedback changes only its label span. Security and service/data contracts remain unchanged.

Substituídos expansores por ações diretas e popover nativo de Preferências; botões/retornos padronizados e feedback de envio preservando ícone. Contratos de serviço/dados/segurança mantidos.
