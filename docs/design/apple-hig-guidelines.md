# Apple HIG design baseline / Padrão visual Apple HIG

Date / Data: 2026-10-20. Maintainer-requested design skill / Skill solicitada pelo mantenedor: [apple-hig-designer](https://github.com/axiaoge2/Apple-Hig-Designer). Decision / Decisão: [ADR-0022](../decisions/ADR-0022-apple-hig-design-baseline.md).

## Authority and adoption / Autoridade e adoção

2026-10-21: [ADR-0025](../decisions/ADR-0025-action-dialogs.md) supersedes routine status/footer/list-density chrome and generic consent checkboxes. Use interactive action windows with explicit submits and independent server security. The maintainer permits JavaScript; full no-JS parity is no longer a UX prerequisite. Existing canonical forms remain practical fallbacks. / Janelas interativas e menos elementos permanentes, sem checkbox genérico; JavaScript autorizado e gates reais preservados.

Current control/navigation rule: [ADR-0024](../decisions/ADR-0024-direct-actions-navigation.md) supersedes Actions/Preferences in-flow disclosures. Use direct resource actions, a labelled native nonmodal Preferences popover, shared icon/label buttons and contextual returns before titles. Informational help/metadata may remain disclosures. Keep no-JS operation, keyboard dismissal/focus, URL preferences and the documented older-browser fallback. [Fresh results](../evidence/direct-controls-results.md). / Regra atual substitui expansores de ações/preferências; ações diretas, popover nativo, controles/retornos consistentes e fallback/teclado/preferências preservados. Disclosures informativos permanecem.

Current maintainer authorization — 2026-10-20: [ADR-0023](../decisions/ADR-0023-hig-fluidity.md) permits cohesive visual redesign for fluidity, superseding the earlier frozen appearance and numeric recipes where changed. Use the full relevant skill, with reviewed adaptation rather than mechanically retaining old styling or copying every effect. Current feedback is 100/200ms; neutral solid canvas replaces V1 gradient/glow, while functional focus remains visible. Historical slices below keep their original evidence scope. [Current results](../evidence/hig-fluidity-results.md). / Autorização atual permite composição coesa e substitui receitas anteriores; sem congelar aparência ou copiar efeitos indiscriminadamente. Feedback 100/200ms e canvas neutro sólido; histórico preservado.

Use this skill for StackEmu visual/UX work. Adopt its emphasis on clear hierarchy, content-first presentation, restrained depth and consistent interaction. It is a community skill, not an Apple publication or proof of HIG/WCAG compliance. The [official HIG](https://developer.apple.com/design/human-interface-guidelines) remains the canonical Apple reference; StackEmu's web/accessibility/security contracts determine how patterns are implemented. Existing tokens remain the implemented baseline until individual migrations pass review. Adopting guidance is not a claim that the entire current UI already conforms.

Usar a skill no trabalho visual/UX: hierarquia clara, conteúdo em primeiro plano, profundidade discreta e interação consistente. É material comunitário, não publicação da Apple nem comprovação de conformidade HIG/WCAG. HIG oficial é referência canônica; contratos web/acessibilidade/segurança do projeto determinam implementação. Tokens atuais seguem como baseline implementado até migração revisada por componente. Adotar diretriz não declara toda a UI já conforme.

## StackEmu mapping / Aplicação no StackEmu

| Area / Área                             | Project rule / Regra do projeto                                                                                                                                                                                                                                                                                                                                                                                 |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Hierarchy / Hierarquia                  | One obvious primary task per context; secondary actions grouped, destructive action unmistakably named. No decorative metrics, fake search/notifications or inactive service cards. / Uma tarefa primária clara, secundárias agrupadas e destrutiva identificada; sem métricas/controles fictícios.                                                                                                             |
| Surfaces / Superfícies                  | Solid by default, neutral canvas, restrained separators/shadows; glass/blur only on explicit request with contrast/performance/fallback review. / Sólidas por padrão, neutros e separadores discretos; vidro/blur apenas por pedido explícito e revisão.                                                                                                                                                        |
| Typography / Tipografia                 | Keep local system fonts and readable semantic hierarchy; do not bundle/download Apple fonts or force iOS sizes onto desktop tables. Preserve full opaque keys, not ellipsis that hides deletion targets. / Fontes locais e hierarquia legível; sem baixar fontes Apple ou impor escala iOS; chaves exatas sem truncar alvo.                                                                                     |
| Rhythm and radii / Ritmo e raios        | Keep 8 CSS-pixel rhythm and documented 4px exceptions; coherent nested radii, not an unrelated radius per screen. Use capsule-shaped standalone primary/secondary buttons as the migration target, not as a requirement to round every disclosure/table control. / Ritmo 8px/exceções 4px e raios coerentes; cápsula como alvo da migração de botões primários/secundários independentes, não de todo controle. |
| Targets and density / Alvos e densidade | Project target minimum remains 44 CSS px; native Apple points are not a web unit conversion or universal WCAG rule. Do not import smaller desktop examples. Density changes spacing, not legibility, key contents or hit targets. / Mínimo do projeto 44 CSS px; não confundir points com unidade web/WCAG. Densidade não reduz leitura/alvos.                                                                  |
| Color / Cor                             | Reuse semantic theme tokens and one accent; measure each foreground/background/state. Do not assume raw system-blue/white or translucent gray pairs pass contrast. Preserve auto/light/dark URL overrides and forced-colors. / Tokens semânticos, um acento e contraste medido; cores do exemplo não garantem contraste. Manter temas/forced-colors.                                                            |
| Motion / Movimento                      | Current ADR-0023 feedback uses 100/200ms and restrained press feedback, disabled by reduced motion. Timing/composition can evolve through review; no looping, hover-only essential actions or focus delay. / ADR-0023 usa 100/200ms e pressão discreta, com redução; receitas revisáveis, sem loops ou foco atrasado.                                                                                           |
| Navigation / Navegação                  | Home stays the service catalog without emulator I/O. Keep native links, labelled preferences and contextual S3 actions; no mandatory mobile tab bar, fake macOS window controls or icon-only Back replacement. / Início segue catálogo sem I/O; links, preferências e ações contextuais, sem imitação obrigatória de janela/tab bar.                                                                            |
| Semantics / Semântica                   | Qute/HTML native buttons, links, forms and disclosures; no click-only div, ARIA tab/menu roles without their keyboard behavior, inline styles/scripts or imported global reset. / HTML/Qute semânticos; sem div clicável, papéis ARIA indevidos, inline ou reset global importado.                                                                                                                              |
| Destructive flows / Destrutivos         | A visual alert is never authorization. Preserve exact-target review, CSRF, one-use confirmation, version/ETag gates and explicit uncertainty under ADR-0021. / Alerta visual não autoriza; preservar revisão exata/CSRF/confirmação única/versão/ETag/incerteza.                                                                                                                                                |

Do not import `resources/design-tokens.css` wholesale: it includes a reset, overlapping utilities, form-appearance changes, focus-outline removal and examples incompatible with existing build/theme contracts. Map only reviewed values into authored semantic tokens. React/Vue examples are design illustrations, not a reason to change Quarkus/Qute/HTMX or add runtime dependencies. Keep existing licensed SVG icons; private-use SF Symbols glyphs are not a portable Windows/Linux web icon system. Review terms separately before introducing any Apple asset; the skill's MIT license does not establish rights to other assets.

Não importar o CSS inteiro: contém reset/utilitários, alteração de aparência/foco e exemplos incompatíveis com contratos atuais. Mapear só valores revisados nos tokens autorais. Exemplos React/Vue não justificam trocar stack/dependências. Manter SVGs licenciados atuais; glifos privados SF Symbols não são portáveis para Windows/Linux. Rever termos antes de introduzir assets Apple; MIT da skill não determina direitos sobre outros assets.
