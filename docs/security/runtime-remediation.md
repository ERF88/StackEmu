# Runtime vulnerability inventory / Inventário de vulnerabilidades

Historical baseline: [Phase 5 CI](https://github.com/ERF88/StackEmu/actions/runs/38587395076), 49 package/CVE findings, 39 distinct CVE identifiers, 18 Ubuntu packages. These are scanner findings, not 49 proven exploitable application defects. / Baseline histórico: 49 pares pacote/CVE, 39 CVEs e 18 pacotes, não 49 falhas comprovadamente exploráveis.

Remediation route: replace the Ubuntu runtime with official Temurin 25/Alpine, preserving required JVM libraries and package metadata. Full-image/JAR rescanning and functional tests decide acceptance; no ignore list, VEX dismissal, severity filter or database deletion is used. / Substituir runtime Ubuntu, preservar bibliotecas/metadados e validar por scan/testes, sem supressão.
